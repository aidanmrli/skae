\section{Support refresh after controlled transfer}
\label{app:support_refresh}

\Cref{tab:support_refresh} reports the controlled-transfer support-refresh diagnostic described in \cref{app:experimental_details}. The stale value is the \(F_{\rm top8}\) family implied by advancing the latent with the learned global transition before a scheduled refresh. The re-encoded value is the family obtained by encoding the current controlled-transfer state at the same event. Higher target-family rates after re-encoding indicate that the encoder can re-select the target-basin support family from the current state without using a support-conditioned local map.
