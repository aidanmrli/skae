\section{Support-routing robustness}
\label{app:routing_robustness}

\Cref{tab:self_routing_deep} reports route-form diagnostics that are not the main table. The deep slice removes boundary-adjacent states, so it is useful as a robustness check rather than the primary deployment setting. The exact \(S_{\rm top8}\) columns should be read as ablations of the support-family router rather than as the headline routing object.

For the gated exact-support diagnostic, let \(m_c\in\{0,1\}^{d_z}\) be the eight-coordinate mask of the exact route \(c=S_{\rm top8}(z_t)\), and let \(\bar z_c\) be the corresponding fitting-set mean. The gated rule masks the centered latent state before applying the learned global transition:
\begin{equation}
  \hat z_{t+1}=\bar z_c+K\bigl(m_c\odot (z_t-\bar z_c)\bigr).
  \label{eq:gated_k}
\end{equation}
This diagnostic asks whether the active coordinates select useful columns or subspaces of the learned transition. The family-local route in the main text asks a different question: whether the same support family can key a post-hoc local linear map.
