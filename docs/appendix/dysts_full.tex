\section{Dysts forecasting diagnostics}
\label{app:dysts_full}

The collected experiment artifacts contain per-(system, seed) Dysts MSE rows. \Cref{tab:dysts_long} reports arithmetic means across systems after first applying \texttt{scipy.stats.trim\_mean} with proportion \(0.25\) to the \(15\) seeds within each system, i.e., averaging the central nine after discarding three values from each tail. We call this seed summary IQM. The soft-block LISTA row is an architecture-specific ablation: it uses two LISTA loops and a sign-split output rather than the one-loop/ReLU recipe of LISTA and LISTA--BD, though all rows use the same \(100{,}000\)-step budget. Its source packet contained \(12\) systems and the paper uses the fixed retained \(10\)-system subset. LISTA--SB improves on Dense MLP in aggregate but has no corrected Dysts significance marker.

The horizon display in \cref{fig:forecasting_horizon_curves} uses the same paper-facing aggregation and retains every one of the ten systems with equal weight after the within-system seed summary. We do not trim systems: doing so would remove two unusually easy and two unusually hard systems separately for each method and horizon, potentially compare different subsets, and hide systematic failure cases. The shaded intervals instead keep the system roster fixed and resample seeds within every system.
