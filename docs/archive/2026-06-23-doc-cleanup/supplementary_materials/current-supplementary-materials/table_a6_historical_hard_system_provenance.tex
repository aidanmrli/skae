\section{Historical benchmark and hard-system provenance}
\label{sec:supp_table_a6_historical_hard_system_provenance}

This appendix table keeps the repaired fair-\(200k\) benchmark, hard-system
stress tests, and historical comparator-selection provenance in one place. These
results are useful for calibration and limitations, but they are not the main
basin-support alignment evidence. All rows below use labels, system identities,
or fixed system families only for evaluation and provenance; they should not be
read as training-time assumptions about known basin counts or basin labels.
