\section{Fixed-17 benchmark system inventory}
\label{sec:supp_table_a2_fixed17_inventory}

\Cref{tab:supp_fixed17_inventory} lists the fixed-17 controlled multibasin
systems used to define the benchmark roster before the current retained-15
paper aggregation. Basin counts and basin-label sources are evaluation
metadata: they are used to annotate basins, audit support--basin alignment, and
construct benchmark diagnostics after training. They are not training inputs
for the sparse encoders, support extraction, support-family construction, or
deployment-facing routing. The current main retained-system summaries exclude
\texttt{multiwell\_strong\_transition} and
\texttt{claude:checkerboard\_potential}; these two remain useful as stress or
falsification diagnostics for the broader fixed-17 inventory.
