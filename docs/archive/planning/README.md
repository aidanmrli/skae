# Archived Planning Docs

These files are historical planning and execution artifacts. There is no active
`docs/planning/` surface: current claims, protocol decisions, display ordering,
and priorities belong in `docs/neurips_sparse_koopman_multibasin.tex` or its
single-purpose appendix fragments.

Most files here describe closed rerun waves, superseded strategy branches, or
agent-specific execution notes. Some links intentionally retain their original
pre-archive locations and may be broken.
