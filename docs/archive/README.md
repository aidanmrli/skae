# Archive

This directory stores historical project material that should not compete with the active paper draft as a source of truth.

Current archive batches:

- `2026-06-23-doc-cleanup/`: superseded status trackers, planning notes,
  old source drafts, supplementary fragments, literature notes, and legacy
  top-level data moved during the documentation cleanup. Duplicate PDFs and
  LaTeX build products were deleted; Git history preserves them.
- `planning/`: older pre-existing planning archive.
- `2026-07-13-full-bibliography.bib`: the superseded broad bibliography before
  the active paper bibliography was reduced to cited entries.
- The three dated Markdown files at this level preserve completed non-paper
  experiment provenance for the control-world-model and Allen--Cahn studies.

Archived files may exceed the active 500-line cap because they are retained for provenance, not day-to-day project state.
Internal links in historical notes may point to their former locations. Do not
repair those links by recreating an active tracker; migrate only a still-relevant
claim or protocol into the paper or its canonical appendix.
